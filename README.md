# Milestone-One

## PROJECT OVERVIEW
This project is a personal website created for my web development class. The website includes an introduction of myself, my interests, and raising awareness about Type One Diabetes.
## ABOUT MY WEBSITE
I created this website to practice using HTML and CSS while learning how to organize and design webpages. I also included pictures that relate to diabetes tech and medical identification to help visitors understand the topic better.
## WEBSITE CONTENT
- my introduction
- information about Type 1 Diabetes
- Dexcom G7 Graph image
- Medical alert identification image
- website navigation and styling
## Project Files
| index.html | Main webpage
| style.css | Controls colors, fonts, layout, and spacing
| DexcomGraph.jpg | image of Dexcom Graph
| typeonediabetesmedicaltag.jpg | Medical alert identification
## Accessibility
I considered accessibility while creating my website 
Some accessibility features include (but aren't limited to):
* Alt text for pictures
* organized headings and content sections
* readable text and color choices
* clear navigation
